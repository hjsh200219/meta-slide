Section · 02

主题与 Tokens

换主题 = 换一份 CSS 变量。其他一切保持不变。

Why · 为什么

好的演讲系统，帮你做三件事

不是做不出漂亮的 slide，是每次都要重新做。

  • ① 统一设计语言

    所有页共用同一套 tokens，字号、颜色、阴影不会跑偏。

  • ② 降低复用成本

    下一次讲同类话题，复制 deck、换数据、换主题即可。

  • ③ 可切换，可演示

    按 T 即可循环切主题、按 A 可切动效，汇报现场加分。

Pattern · 双栏

概念 ⟷ 示例

左栏 · 概念

一个主题 = 一组 CSS 变量。把颜色、字体、圆角、阴影全部收到 :root 里。

  • — tokens 定义语义，不写具体色值
  • — base.css 用 tokens 排版
  • — 每个主题只改变量

右栏 · 示例

:root {
  --bg: #fff;
  --text-1: #0c0d10;
  --accent: #3b6cff;
  --radius: 18px;
}
.card {
  background: var(--bg);
  color: var(--text-1);
  border-radius: var(--radius);
}

Trade-offs · 诚实的取舍

纯 HTML 演讲：好在哪里，痛在哪里

✓ 好处

  • 零构建：一个文件就能跑
  • 可 diff：Git 友好，好 review
  • 可编程：动效自由定制
  • 可分发：URL / PDF / PNG 都行

✗ 痛点

  • 协作不像 Keynote 那样实时
  • 非程序员上手稍陡
  • 复杂动效仍需写 JS
  • 部分字体在离线环境缺失

Product · 03

左图右文，最常用的一页

  • 图占一半，说明占一半 —— 视觉与论述各不抢戏
  • 竖图、方图、横图都能放：框决定比例，图自己 cover
  • 想把图放右边：给 .split 加 flip
图文各半。框比例由 --img-ratio 控制，这里用 4/5 竖构图；图片换成横图也不会破版。
