Evaluation method
Four steps, one protocol.
Every model runs the same pipeline under identical conditions
01.
Select
Pick public benchmarks with verifiable answers and a fixed test split.
02.
Run
Execute each model with default settings, three runs per task.
03.
Score
Grade outputs automatically and average the scores across runs.
04.
Verify
Reproduce the top results independently before publishing.
Same prompts, same hardware, same scoring scripts for every model
